# Jiayu Wang · Coastal Plant Ecology

Academic homepage: https://jiayu147.github.io/

A responsive static website with verified biographical information, five publications, two field experiments, study species and contact information. The original experimental photos and figure were recovered from the matching asset paths on Jiayu Wang’s earlier Weebly website.

## Edit the website

- `index.html`: biography, education, publications, projects, species and contact details.
- `styles.css`: layout, colors, mobile breakpoints and print styles.
- `app.js`: mobile navigation, research tabs, publication filters and copying.
- `publications.bib`: downloadable bibliography; update alongside the publication list.
- `assets/`: original research images and the site icon.

Old page URLs redirect to corresponding sections of the homepage. No build or dependencies are needed. GitHub Pages can serve the repository root from the `master` branch; `.nojekyll` disables Jekyll processing.

## Validation

JavaScript syntax, navigation/tab/filter/copy behavior, HTML anchors, local assets and all five DOI records have been checked. Desktop and mobile visual browser QA has not been performed because the required browser capability is unavailable in the current environment.
